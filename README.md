## 🧠 Knowledge Engine

`js/knowledge.js` contient une base de connaissances locale structurée. Le cerveau de Nexus IA recherche d'abord une notion correspondante avant de retourner sa réponse par défaut.

La V0.7 comprend notamment des notions de trigonométrie, Pythagore, Thalès, aires, classes grammaticales, histoire, SVT, Python, HTML, CSS, JavaScript et une information locale sur le Collège Saint Joseph La Salle de Rodez.
